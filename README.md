### Five reasons that you should use PuppyAgent to create AI agents to work with you.

1. **Human-Agent Interacts**: PuppyAgent allows you to instruct your agents in any time.
2. **Workflow Management**: PuppyAgent allows you to manage the workflow by you or your agents. Just like running a company!
3. **Multi-Agents in Parallel**: PuppyAgent allows agents to work in parallel, one of the agent's crash will not affect the others.
4. **Scalable & Modular**: PuppyAgent is scalable, you can modify the prompt for tools, agents.
5. **Open-source**: PuppyAgent is open-source, you can run it locally and don't need to worry about your information being leaked.
