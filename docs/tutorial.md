
## What is LLM agent? 
An LLM agent (Large Language Model agent) is a specialized software entity that utilizes a Large Language Model to autonomously perform or assist in a wide array of tasks through natural language processing and understanding capabilities. Compared with regular LLM applications, agents emphasize more on doing and executing instead of only chatting or searching.

For example, you may want your AI minion to automatically write and execute a programm for you instead of telling you how to write and test Python code. 

## Elements of intelligent agents
What's the most basic difference between an LLM and an agent? 
Let me give you a hint:

- A LLM predicts the next token.
- An agent predicts the next action.

Predicting an action is much more complicated than predicting a token. 

To predict the next action, an agent must  **sensing the environment**, **making decisions**, and **executing actions**.
